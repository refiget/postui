# 鼠标交互

## 主界面

| 区域 | 操作 |
| --- | --- |
| 请求列表 | 单击选择请求；同一请求双击发送 |
| 请求列表滚动 | 鼠标滚轮、滚动条点击、滚动条拖拽 |
| 请求预览 | Body 值点击编辑；Params/Headers 标签切换；表格行点击、编辑、添加、删除 |
| 请求方法 | 点击方法区域循环切换标准方法 |
| 响应区域 | Raw、Formatted、Headers 标签切换；格式切换；响应放大；操作菜单 |
| 响应滚动 | 鼠标滚轮、滚动条点击、滚动条拖拽 |

## 页面与弹窗

| 区域 | 操作 |
| --- | --- |
| 变量页 | 行选择、值编辑、滚动条点击和拖拽 |
| Params/Headers | 行选择、编辑、添加、删除 |
| cURL 导入 | 字段聚焦、字段光标定位、场景选择、取消、确认 |
| 场景选择 | 下拉菜单点击、悬停和滚动选择；触发按钮再次点击关闭 |
| 响应操作 | 下拉菜单点击、悬停和滚动选择；下载、复制响应体、复制响应头、提取变量 |
| 工作区选择 | 筛选、最近工作区选择、目录输入 |
| 帮助页 | 滚动、点击外部区域关闭 |
| 搜索 | 字段聚焦、光标定位、点击外部区域确认 |

## 当前限制

- 主界面方法区域没有独立的下拉控件状态。
- 右键没有操作。
- 主界面既有按钮和 cURL 按钮在左键释放时确认；列表和表格内容区域在左键按下时处理。
- 面板高度小于下拉菜单高度时菜单覆盖触发按钮所在行，该行的条目按触发按钮处理。
