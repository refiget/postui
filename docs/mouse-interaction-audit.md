# 鼠标交互

## 主界面

| 区域 | 操作 |
| --- | --- |
| 请求列表 | 单击选择请求；同一请求双击发送 |
| 请求列表滚动 | 鼠标滚轮、滚动条点击、滚动条拖拽 |
| 请求预览 | Body 值点击编辑；Params/Headers 标签切换；表格行点击、编辑、添加、删除 |
| 请求方法 | 点击方法区域循环切换标准方法 |
| 响应区域 | Raw、Formatted、Headers 标签切换 |
| 响应滚动 | 鼠标滚轮、滚动条点击、滚动条拖拽 |

主界面没有按钮控件。响应格式切换、响应放大、发送、新建、场景和变量都由键盘触发。

## 页面与弹窗

| 区域 | 操作 |
| --- | --- |
| 变量页 | 行选择、值编辑、滚动条点击和拖拽 |
| Params/Headers | 行选择、编辑、添加、删除 |
| cURL 导入 | 字段聚焦、字段光标定位、场景字段点击聚焦 |
| 场景选择 | 下拉菜单点击、悬停和滚动选择；点击菜单外关闭 |
| 响应操作 | 下拉菜单点击、悬停和滚动选择；下载、复制响应体、复制响应头；点击菜单外关闭 |
| 工作区选择 | 筛选、最近工作区选择、目录输入 |
| 帮助页 | 滚动、点击外部区域关闭 |
| 搜索 | 字段聚焦、光标定位、点击外部区域确认 |

## 当前限制

- 主界面方法区域没有独立的下拉控件状态。
- 右键没有操作。
- 列表和表格内容区域在左键按下时处理。
- 面板高度小于下拉菜单高度时菜单按屏幕边界定位。
